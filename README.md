# Data Directory

This directory is used to store the FordA dataset files.

## Dataset Information

The data is automatically downloaded from:
https://raw.githubusercontent.com/hfawaz/cd-diagram/master/FordA/

Files:
- `FordA_TRAIN.tsv` - Training data
- `FordA_TEST.tsv` - Test data

## Note

The `.tsv` files are ignored by Git (see `.gitignore`) to keep the repository lightweight.
The data loading script automatically downloads them when needed.
